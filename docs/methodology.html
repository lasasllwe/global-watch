Method & sources

How a brief is made

  1. Collect. Every day, headlines, short snippets and links are read from the public RSS feeds below. No full articles are copied.
  2. Group. Headlines about the same event are grouped into stories. Only stories covered by at least two regions are kept, so the brief is not dominated by one part of the world.
  3. Summarize. An AI model (Google Gemini) writes a neutral summary using only the grouped headlines, then describes how each region frames the story. Source links are attached by code, not written by the model.
  4. Check. Entries without a valid citation are discarded automatically. Summaries can still be wrong: follow the links.

Source labels

Each outlet is labeled by region and ownership (independent, private, public broadcaster, NGO, state-funded) so you can see where a framing comes from. State-funded outlets are only included when clearly labeled.
